### What I'm working on

**[Alkometriikka](https://alkometriikka.fi)** — An independent platform for exploring and analysing Alko's product catalogue and pricing data.

What started as a small experiment has grown into a fairly comprehensive application featuring:

- Automated data ingestion and synchronisation
- Product catalogue, search and filtering
- Historical price tracking and statistics
- Product availability information
- RSS and JSON feeds
- API integrations and a daily guessing game
- Automated deployments and static page generation

Built primarily with **Svelte, TypeScript and Bun**, with GitHub Actions, GitHub Pages and Cloudflare handling much of the infrastructure.

[Explore the project](https://github.com/leevilaukka/alkometriikka) · [Visit the website](https://alkometriikka.fi)
